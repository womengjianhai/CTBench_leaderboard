01 / THE BENCHMARK

A correct answer is
only part of the story.

CTBench connects task outcomes with the actions an agent takes to reach them. Examine correctness, localization, and evidence as distinct capabilities.

01

Operational tasks

Reason across devices, interfaces, routing and policies using a permitted diagnostic interface.

How to read these results +

AccuracyWhole-answer correctness for the selected task family. RCA and path scores have different denominators: 126 and 108 tasks.

Localization & task capabilityIoU measures matching objects or endpoints; identification matches root-cause labels, while restoration matches path edges.

Evidence F1Agreement between diagnostic device-command actions and expert golden steps. A correct answer does not imply complete evidence.

Each row evaluates a model together with its harness. Differences between rows do not isolate the effect of the model alone.
